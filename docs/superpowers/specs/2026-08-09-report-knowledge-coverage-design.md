# 报告知识全覆盖设计

## 目标

不公开原始 PDF、逐字正文和原图，但把报告中可用于 FDE 问答的知识完整转成公开、可检索、可追溯的结构化资产，重点补齐岗位、薪酬和行业现状。

## 产物

- `knowledge/report-page-index.json`：覆盖 83 页的逐页索引，记录页面类型、章节、主题、内容摘要和证据状态。
- `knowledge/jobs-and-compensation.md`：岗位职责、能力、学历经验、工作方式、国内外薪酬样本和回答边界。
- `knowledge/industry-and-market.md`：招聘市场、企业类型、国内外差异、行业趋势和时效风险。
- `knowledge/fde-insight.graph.json`：增加岗位市场、薪酬和行业趋势实体，并保留页码证据与待核验标签。
- `SKILL.md`：将薪酬、招聘和行业现状问题路由到新增知识文件。

## 内容边界

- 不发布报告全文、原图、带签名资源地址或可还原报告版式的完整转录。
- 数字必须包含样本量、采集窗口、币种或薪酬周期，并标明报告页码。
- 招聘数量、薪酬、公司岗位和政策统一视为时效性事实；回答时先陈述报告样本，再提示实时核验。
- 页面索引用摘要表达，不复制大段原文。

## 验收标准

- 逐页索引恰好覆盖第 1 至 83 页，无重复、无缺页。
- 岗位薪酬专题包含国内、海外、能力、经验、出差和样本偏差。
- 行业专题包含招聘趋势、岗位命名、雇主类型、中美差异和政策信号。
- Skill 对薪酬、招聘、待遇、行业趋势问题有明确路由和回答规则。
- 自动化测试校验覆盖、证据字段、时效标签和公开边界。
